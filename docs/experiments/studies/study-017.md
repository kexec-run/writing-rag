# MDX content ingestion and retrieval ablations

Study ID: `study-017`

Disposition: `results-only`
Decision: MDX ingestion is retained; global ranking did not demonstrate an article-output change.

## Question

Does adding related MDX prose change evidence retrieval and the generated article?

## Method and controls

This study record consolidates a research line from the private experiment history. It covers **15 held artifact directories**; that count is an inventory count, not an execution count, a sample size or a count of independent cases. Individual payloads were not copied into the public release.

## Findings

In the source ablation, added MDX prose was present in the index but ranked below the usable cutoff. All six conditions selected the same top ten base chunks and generated byte-identical outputs.

## Evidence and limits

The target-derived scaffold remained fixed in that test, so it isolates source availability and ranking rather than scaffold independence. See the [public decision ledger](../../architecture/experiment-ledger.md); exact source-line provenance is retained in the private inventory.
