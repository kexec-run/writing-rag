# Instagram chain retrieval

This folder records an exploratory filtered-chain retrieval direction. The
catalog links it to the Instagram conversation-chain study; its decision does
not change the canonical ingestion path.

## Public availability

- Catalog disposition: `pending sanitization` ([study-006](../../../docs/experiments/studies/study-006.md)).
- Present in this folder: `instagram_mdx_filtered_ablation.py` and this README.
- Omitted: private Instagram exports, selected message windows, labels and run outputs; the retained script has not been established as a standalone public experiment.
- Reproduction limit: no corpus-backed result can be reproduced from this snapshot. Treat the code as historical research material, not a supported entrypoint.
