# Instagram conversation episodes

This folder retains exploratory episode-construction contracts and validators.
They are not the production Instagram ingestion implementation.

## Public availability

- Catalog disposition: `pending sanitization` ([study-007](../../../docs/experiments/studies/study-007.md)).
- Present in this folder: `__init__.py`, `decide_episode_experiment.py`, `decide_gated_experiment.py`, `manifest.json`, `validators.py`, and this README.
- Omitted: private Instagram messages, source identities/configuration, corpus-derived fixtures, model cache, and generated evaluation results.
- Reproduction limit: the retained files do not constitute a complete public experiment; no episode-quality metric is reproducible from this folder.
