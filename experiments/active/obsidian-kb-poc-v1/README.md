# Obsidian knowledge-base prototype v1

This folder preserves a local knowledge-base prototype. Its catalog status is
pending sanitization; the presence of scripts does not mean the original
personal knowledge base or end-to-end behavior is available publicly.

## Public availability

- Catalog disposition: `pending sanitization` ([study-021](../../../docs/experiments/studies/study-021.md)).
- Present in this folder: `generate_title_variants.py`, `generate_titles.py`, `score_obsidian_poc.py`, `select_slice.py`, and this README.
- Omitted: the private Obsidian vault, local configuration, model weights/cache, and generated title/score artifacts.
- Reproduction limit: no public input fixture or complete runnable bundle is included; do not treat these scripts as a supported demo.
