# UEmbed Instagram retrieval screening

This folder preserves code from an exploratory UEmbed screening and retrieval
direction. The catalog marks it pending sanitization because the public
checkout does not provide a complete, independently reproducible study.

## Public availability

- Catalog disposition: `pending sanitization` ([study-037](../../../docs/experiments/studies/study-037.md)).
- Present in this folder: `instagram_screen.py`, `ranking.py`, `scarcity_first_selection.py`, `stage2_combine.py`, and this README.
- Omitted: private Instagram corpus and frozen cases, relevance labels, model weights/cache, and result artifacts.
- Reproduction limit: these retained components are not an end-to-end supported entrypoint; reported semantic screening or retrieval results cannot be reproduced here.
