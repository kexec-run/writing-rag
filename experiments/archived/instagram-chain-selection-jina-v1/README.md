# Archived Jina Instagram chain-selection experiment

This archived experiment evaluated Jina as an auxiliary text-selection signal
for Instagram conversation-chain candidates. The study decision is
`structural_only`; it was not promoted as the production chain selector.

## Public availability

- Catalog disposition: `results-only` ([study-008](../../../docs/experiments/studies/study-008.md)).
- Present in this folder: `decide_jina_candidate_selection.py`, `jina_candidate_selection_experiment.py`, and this README.
- Omitted: private Instagram conversations, frozen anchor labels, model weights/cache, and per-anchor experiment outputs.
- Reproduction limit: retained scripts are historical research code, not a complete public rerun bundle; the recorded result is summarized in the linked study page.
